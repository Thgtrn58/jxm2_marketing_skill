# JX1M2 Skills

Claude Code skills for the JX1M2 marketing team.

| Skill | Purpose |
|---|---|
| `insight-jx1m2-for-marketing` | Player insight + brief templates for content, community, and ads |

## Install

Private repo: you need repo access and git logged in to GitHub on your machine.

```bash
npx skills add Thgtrn58/jxm2_marketing_skill
```

Update to latest:

```bash
npx skills update
```
